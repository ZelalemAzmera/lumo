❌ Deficiencies of Standard Embed in Savanna

The unmodified Savanna template uses a generic HTML5 video or basic video.js embed with no captions, no Ethiopian Sign Language, and no audio descriptions. Keyboard-only learners face keyboard traps and low-contrast control bars. 

<!-- Inaccessible default snippet -->
<div class="video-container">
  <video controls src="lesson.mp4"></video>
</div>

✅ Lumo Enhanced: Zero CSS Pollution via Shadow DOM

In savanna/pages/concept-with-navigation.html, inside #curriculum_navigation_content .savanna-styles, add the single script tag and place <db-player>. Savanna's 1.5MB of Bootstrap CSS does not alter Lumo's buttons. 

<!-- 1. Load module -->
<script src="/module/db-player.js" defer></script>

<!-- 2. Place component -->
<db-player 
  src="/videos/web-architecture.mp4" 
  captions="/captions/en.vtt,/captions/am.vtt" 
  sign="/sign/esl.mp4" 
  describe="/audio/ad.mp3" 
  lang="am">
</db-player>

Integration Tier

API Explorer & Three Integration Levels

Lumo provides three distinct adoption levels to fit any LMS architecture.

LEVEL 1

JavaScript Embed

Drop onto any static or dynamic page. Zero backend configuration required.

REST API (FastAPI)
