Lumo Accessible Media Player

Digital Bridge Accessibility Hackathon 2026 — Track 2: Accessible Learning Media

Gate Test Harness: WCAG 2.2 AA compliant, keyboard-operable, dual English/Amharic captions, movable Ethiopian Sign Language overlay, and Audio Description.

Keyboard Shortcuts Map

  • Space / K — Play / Pause toggle
  • ← / → — Seek back/forward 5s
  • ↑ / ↓ — Volume up/down 10%
  • M — Mute / Unmute toggle
  • C — Toggle Captions (Off → EN → AM)
  • S — Toggle Sign Language window
  • D — Toggle Audio Description
  • F — Fullscreen toggle

Ethiopian Localization (Track 2)

  • Amharic Captions: Rendered with Noto Sans Ethiopic font, LTR script direction, and line-height 1.65.
  • EthSL Window: Movable overlay with time-sync; draggable via header or arrow keys when focused.
  • Screen Reader Ready: Live announcements for NVDA, TalkBack, and JAWS.
